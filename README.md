# Shazam

Shazam is Apple's music recognition service that identifies songs from audio fingerprints. Originally launched in 2002 and acquired by Apple in 2018, Shazam processes over 1 billion song identifications per month. Developer access is available via Apple's ShazamKit framework (iOS, macOS, tvOS, visionOS, watchOS, Android) and a third-party REST API on RapidAPI.

**Human URL:** https://www.shazam.com  
**Developer URL:** https://developer.apple.com/shazamkit/

## APIs

- **ShazamKit** - Apple's official SDK for music recognition; no per-request charges with Apple Developer Program membership ($99/year)
- **Shazam REST API (RapidAPI)** - Third-party wrapper providing song detection, charts, artist metadata via REST; tiered plans from $24.99/month
